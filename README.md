**搞快点** 是 Windows 桌面版 Microsoft Excel 的原生加载项，把工程造价日常高频的表格操作——分级、求和、排版、导表——做成一键智能处理，并内置 AI 问答、自定义公式与宏生成能力。使用 Excel 原生功能区和对象模型，不含网页或 WebView；只需 .NET Framework 4.8，无需 Python 或其他辅助软件。

## 功能总览

| 功能 | 它解决什么问题 |
|:---|:---|
| 🗂️ 智能分级 | 按编号一键重建表格分组，支持清除、恢复与一至三级分级显示 |
| ➕ 智能求和 | 识别父子层级，预览 `SUM` 公式后勾选写入，可一键撤销 |
| ✅ 求和校验 | 只读核查父子金额是否一致，双击结果直达问题行 |
| 🖨️ 排版 | 智能分页 + 中西文字体自动排版，多表批量处理 |
| 📤 导表 | 一键完成清理、排版、分级、打印设置并保存导出，可转飞书云表格 |
| 🧹 工作簿工具箱 | 瘦身、体检、文档信息管理、解除文档限制 |

| 📮 飞书云表格 | OAuth 登录后上传整个工作簿、导出飞书云表格 |

## 表格处理

- **智能分级 / 清除分级 / 恢复上次分级**：按编号重建所选工作表的 Excel 原生分组，可默认仅处理当前表或批量选择；恢复只覆盖当前会话最近一批分级和隐藏状态，不恢复单元格编辑。两种操作均展开原隐藏行列，不改动数值、公式与样式。
- **分级显示**：显示一级、二级、三级或全部展开。
- **智能求和 / 撤销上次求和**：预览层级父项的直接子项并生成 `SUM` 公式，逐项确认写入；支持撤销当前 Excel 会话最近一批求和。公式、数据或范围变化后会拒绝覆盖。
- **求和校验**：只读检查父子金额，不写公式、不修改金额，双击结果可定位；结果仅用于复核，不等同于完整审计。
- **排版**：智能分页按「表头定宽、边框定界」识别表格，宽度压成一页、高度自然分页，自动重复表头、生成页码，完成后可一键恢复原打印设置；字体排版自动区分中文（宋体、黑体）与西文（Times New Roman）分别设置，支持多表批量执行并回读实际生效字体。
- **导表（水电工程提项目）**：一个「导表」按钮走完全流程——清理、排版、分级、打印设置、保存，结果输出到原文件旁的「提项目」文件夹，不覆盖已有结果，不修改源工作簿；范围确认页可选择导出到飞书云表格，「上传整个工作簿」上传的是包含未保存修改的临时副本。另有「水电工程导表方法二」预览版，用自适应矩形合并扫描提速并自动记录耗时，便于对比取舍。

导出减少重复剪贴板复制、合并相同边带并批量提交打印设置。实际耗时、组合工作表粘贴及字体显示仍须在 Windows Excel 中确认。

## 工作簿工具箱

- **瘦身**：扫描图片与嵌入对象，可压缩大图（超过 1600 像素的 PNG、JPEG）、删除对象，另存精简副本并重新体检，不覆盖源文件或已有输出。
- **文件体检**：只读扫描工作簿结构（支持 `.xlsx/.xlsm/.xltx/.xltm`），快速摸清文件状况。
- **修改工作簿信息**：标题、作者、类别、备注、单位五个字段，写入前显示新旧值逐项确认；「随机填充（神话）」可用古今中外神话人物趣味填充。
- **解除文档限制**：为有权处理的 Open XML 文档生成无编辑限制的新副本，不破解打开密码或加密，不修改源文件。

## AI 助手

- **AI 设置**：管理模型配置并测试连接；支持 OpenAI 兼容接口、智擎/Dify 单轮工作流，配置列表 **★** 表示默认。
- **生成公式**：一句话描述需求，AI 补全名称、参数和算法草案，审阅、试算后再保存进本地公式库。
- **生成宏**：描述宏要完成的任务，AI 生成 VBA 标准模块过程和执行计划；写入前必须审阅完整代码与风险提示，并自动创建目标工作簿备份。宏不会自动运行，VBA 不在沙箱中执行，运行前请自行审查代码。
- **刷新 AI 结果 / 取消 AI 任务 / 结果转为值**：重试所选公式、停止全部排队请求、把完整溢出范围转为静态值。

## AI 公式

先在“AI 设置”保存模型配置并设为默认（★），检测连接和表格能力。不依赖本地适配器或 Python。

```excel
=GKD("问题")
=GKD("要求",,1)
=GKD("概括材料用途",A2)
=GKD("整理成表格",A2:C8,1)
=GKD()
```

`=GKD("问题")` 进行纯文本问答，不会隐式读取当前选区、其他单元格或工作簿；提示词中写出单元格地址也不会自动读取。需要数据时必须用第二参数明确传入。`=GKD("要求",,1)` 允许不带数据生成二维表格；第三参数省略或填 `0` 返回单值，填 `1` 返回表格。`=GKD()` 显示欢迎语“感谢使用！”，不请求模型。每次调用独立单轮。二维结果需支持动态数组的 Excel，输出区域须空白。

点击“★ 使用帮助与示例”查看公式写法，失败时可点击“打开诊断日志”排查；修改默认配置后，选中已有结果手动刷新。详细说明见 [发行版使用说明](docs/发行版使用说明.md)，在包内对应唯一的《使用说明.md》。

## 本地自定义公式

在“AI 助手 → 自定义公式”查看本地列表，核对每项的含义、参数顺序及单位、适用范围和算法定义；可新建、编辑、删除、导入或导出 JSON。手写定义或使用“AI 设计”生成草案，均须预览并确认保存；生成成功或通过格式检查不代表算法、工程规则或结果已验证。

- **确定性表达式**：在本地计算，仅支持声明的输入名、数字、`+ - * / ^`、括号，以及受限的同维度单位换算 `CONVERT(X,"mm","m")`。它不是 Excel 任意函数解释器，也不运行任意生成代码。
- **AI 提示词模板**：调用“AI 设置”中的当前默认后端处理显式传入的值，仍是模型输出，须复核；不会执行模板中的代码。
- 保存并启用后，可用动态名称别名 `=PIPE_MASS(A2,B2)`，或稳定入口 `=GKD_CUSTOM("PIPE_MASS",A2,B2)` 调用同一命名定义。示例以已建立的 `PIPE_MASS` 定义为前提，不是内置已验证算法。按声明顺序提供全部参数，最多声明 32 个参数、传入 32 个值；确定性表达式的每个参数须为单个有限数值。
- 这些辅助公式保存在当前 Windows 用户的 `%LOCALAPPDATA%\GKD\custom-formulas.json`，不会随工作簿自动携带。换电脑或分享前导出 JSON，再在目标电脑导入并检查名称冲突；AI 类型还需单独配置默认后端。公式 JSON 不含 API Key 等凭据，请勿把密钥写进说明或模板。删除、停用或改名会影响引用它的公式。

普通发行包不含凭据。只有显式传入 `--private-test-key-file` 的授权构建附带独立工作流密钥，并使用“私密版”包名；请勿转发私密包。新包凭据文件为 `gkd-workflow.key`。配置界面可载入独立智擎工作流参数，不会自动保存；AI 模型配置中的密钥使用 Windows 当前用户加密保护。AI 请求中的提示词与显式数据会发送到所配置的服务，请按组织要求使用。

## 飞书云表格

在导出窗口内打开“飞书设置”，填写 App ID 与 App Secret，通过系统浏览器完成 OAuth 登录（回跳本机 `127.0.0.1` 自动核验用户身份），即可导出飞书云表格、上传整个工作簿。密钥与用户令牌在本机使用 Windows DPAPI 加密保存，不依赖外网资源或常驻服务。

授权范围共五项：`drive:file:upload`、`docs:document:import`、`drive:drive.metadata:readonly`、`docs:document.media:upload`、`offline_access`，均需在飞书开放平台「权限管理」开通并通过审批，缺任一项对应步骤会失败。首次使用前须在应用的「安全设置 → 重定向 URL」登记回调地址。

> **1.11.2 版本重点修复素材上传权限**：授权范围补齐后，上传素材不再出现 `99991679` 权限错误。

## 安装与卸载

1. 从[发布页](https://github.com/syydds18/GKD/releases)下载完整 ZIP 并解压到本地文件夹；不要在 ZIP 预览中运行，也不要单独移动安装程序或 `payload`。
2. 安装前保存并关闭 Excel。运行 `安装与卸载.exe`，选择实际使用的 Excel 版本与位数，然后点击“一键安装”。
3. 启动 Excel，在 **搞快点** 选项卡中使用功能。
4. 卸载可从安装器点击“卸载加载项”，也可从 Windows“应用/程序和功能”卸载。重新安装或切换 Excel 版本/位数前，先卸载旧版。

安装器仅为当前 Windows 用户安装，不要求管理员权限。卸载遇到 Excel 时会先请求正常关闭；若超时，强制关闭是单独操作并需再次确认，可能丢失所有未保存内容。不会自动修改宏/信任中心设置或绕过组织策略。未签名 XLL 可能被企业策略阻止，请联系 IT。

## 使用须知

- 先保存原文件，建议在副本上验证。加载项不会自动保存工作簿。
- 智能分级会重建所选表的原生分组并展开隐藏行列；分级操作可能清空 Excel 原生撤销栈，不要依赖 `Ctrl+Z`。
- “恢复上次分级”不是通用撤销；新增、删除或移动行列后不要使用。关闭 Excel 后恢复快照失效。
- 智能求和只改勾选的父项单元格，不自动舍入；请核对预览与业务汇总口径。求和校验采用原有候选匹配规则，不能保证发现所有公式问题。

# 搞快点 1.6.0 使用说明

Windows 桌面版 Excel 原生加载项，提供智能分级、智能求和、求和校验、水电工程提项目、纯文本 AI 问答和本地自定义公式。需要 .NET Framework 4.8，无需 Python 或其他本地适配器。

下载与更新：https://github.com/syydds18/GKD/releases

项目源码：https://github.com/syydds18/GKD

## 安装与卸载

完整解压 ZIP 到本地文件夹，保持“安装与卸载.exe”、同名 `.exe.config` 与 `payload` 文件夹相邻。保存并关闭 Excel 后运行安装器；安装器自动检测 Excel，也可手动选择 EXCEL.EXE，位数以 Excel 为准。已有版本请先卸载。

安装只影响当前 Windows 用户。卸载可从安装器或 Windows“应用/程序和功能”执行；先请求正常关闭 Excel，超时后可单独确认强制关闭，未保存内容可能丢失。未签名 XLL 可能被组织策略拦截，请联系 IT。

支持 Windows 桌面 Excel 2010+（x86/x64）；不支持 WPS、macOS、网页版或原生 ARM64 Excel。AI 动态表格需 Microsoft 365、Excel 2021/2024 等支持动态数组的版本。

## 功能区从左到右

1. **智能分级**：智能分级按编号重建所选表分组；清除分级删除分组。两者均展开原隐藏行列，不修改数值、公式或样式。恢复上次分级只恢复当前 Excel 会话最近一批分组和隐藏状态，插入、删除或移动行列后不要使用。
2. **智能求和**：预览父项直接子项的 `SUM` 公式，只写勾选项；撤销上次求和恢复当前会话最近一批操作，快照变化时拒绝覆盖。
3. **求和校验**：只读检查父子金额，不修改公式或金额；双击结果可定位。检查不能代替完整业务复核。
4. **分级显示**：显示一级、显示二级、显示三级或全部展开。
5. **项目提取**：水电工程提项目选择工作表和打印范围，在副本中清理并导出，不修改源工作簿；可显式保存或加载导出范围方案。
6. **AI 助手**：AI 设置管理模型；自定义公式管理本地列表、含义、参数和算法，支持编辑、删除及 JSON 导入导出；刷新 AI 结果只重试所选公式；取消 AI 任务取消全部排队和运行中的请求；结果转为值转换完整溢出范围，移除公式前建议保存副本。
7. **说明**：使用说明打开功能介绍及可点击的发布页、仓库链接。

## AI 配置与帮助

打开“AI 设置”，填写自己的接口与 API Key，执行连接/鉴权及表格能力测试，保存后设为默认，配置列表中 **★ 表示默认配置**。点击 **“★ 使用帮助与示例”** 查看参数说明、公式示例和常见问题。模型名称 / 路由可留空；服务端要求时再填写。API Key 输入框的眼睛按钮可显示或隐藏密钥，保存的个人配置由 Windows 当前用户加密保护。

“填入已验证智擎测试配置”只填入独立工作流参数，不会自动保存。普通发行包不带密钥；仅经授权构建的“私密版”包可附带独立工作流密钥，安装后由预设载入，请勿转发私密包或密钥。新包凭据文件为 `gkd-workflow.key`。

## AI 公式与结果

```excel
=GKD("问题")
=GKD("要求",,1)
=GKD("概括材料用途",A2)
=GKD($F$1,A2:C2)
=GKD("整理成材料名称、规格、数量、单位四列，包含表头",A2,1)
=GKD("整理",(A1,C3:E3),1)
=GKD()
```

第二参数可省略：`=GKD("问题")` 只发送提示词，不会隐式读取当前选区、其他单元格、工作表或整本工作簿；在提示词里写 A2 也不会读取 A2。需要资料时，用第二参数明确引用或传值。第三参数省略或填 `0` 返回单值，填 `1` 返回二维表格；`=GKD("要求",,1)` 允许不带数据生成表格。每条公式独立单轮，没有多轮记忆。输入 `=GKD()` 显示欢迎语“感谢使用！”，不请求模型；插件事件启用时也可将裸 `=GKD` 补成空调用。引号使用半角 `"`。

表格依次为表名、空行、表头及数据，表名跨列居中而不合并，表头和数据带边框；自动设置字体和字号。溢出区域须空白，不会覆盖已有内容。同表不连续引用用括号包住；区域按 Excel 返回顺序纵向拼接，不同宽度补齐，补齐超过 10000 格时展平成单列。实际输入引用上限为 10000 格。

修改默认配置后需选中已有公式并点击“刷新 AI 结果”。“结果转为值”会处理完整溢出区域，即使只选择其中一格；转值后不能自动恢复公式。本版不显示估算 Token。

## 本地自定义公式

从“AI 助手 → 自定义公式”打开本地列表，选中公式可查看含义说明、参数顺序、输出单位及算法定义。可新建、编辑、删除，或通过 JSON 导入 / 导出。填写参数单位、适用范围和无效输入的处理要求，预览并确认后才保存；删除也需确认，会影响使用该定义的公式。

两种定义类型：

- **确定性表达式**在本地计算，支持数字、声明的输入名、`+ - * / ^`、括号及受限单位换算，例如 `CONVERT(X,"mm","m")`。换算仅支持内置单位的同维度转换，单位名区分大小写；不支持任意 Excel 函数或任意生成代码。
- **AI 提示词模板**把模板要求与显式参数值提交到当前默认 AI 后端；需要先保存默认模型配置。模板不执行代码，输出仍须人工复核。

可以手写定义，也可填写“AI 设计需求”，预览将发送到默认后端的设计提示词，再请求草案。AI 草案不会自动保存；核对含义、输入顺序、单位、表达式及边界条件后，再点“预览并确认保存”。格式检查不验证算法正确性，生成的工程算法和结果尚需用独立算例与适用规则复核。

已保存且启用名为 `PIPE_MASS` 的定义后，两种调用指向同一公式：

```excel
=PIPE_MASS(A2,B2)
=GKD_CUSTOM("PIPE_MASS",A2,B2)
```

前者是动态注册的名称别名，后者是稳定函数入口；示例不表示内置了已验证的钢管算法。Excel 标识和输入名使用大写字母开头的 A–Z、数字或下划线，最长 31 字符；公式标识不能与 Excel 或加载项保留名、单元格地址冲突。按定义声明的顺序提供全部参数，最多声明 32 个参数、传入 32 个值；确定性表达式的每个参数须为单个有限数值。AI 类型可显式引用区域，但仍受输入单元格上限限制。

辅助公式库保存在当前 Windows 用户的 `%LOCALAPPDATA%\GKD\custom-formulas.json`，属于本地用户配置，不会自动嵌入工作簿。分享或换电脑时，从原电脑导出 JSON，在目标电脑导入并预览确认；同名或同标识冲突时，先检查和处理旧定义。导出的是公式定义，不含 API Key 等密钥；不要把密钥写进含义或模板。AI 类型需在目标电脑另行设置默认后端。停用、删除或改名后，依赖该定义的公式可能无法继续计算。
